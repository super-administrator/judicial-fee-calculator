# 司法速算器

司法速算器是一款面向法律工作者的桌面计算工具，基于 Python 3 和 PySide6 开发，重点适配银河麒麟等 Linux 桌面系统。

## 主要功能

- 诉讼费用计算：支持案件受理费、减半金额、保全费和执行费，输入金额后自动计算。
- 案件基数配置：可自定义“离婚无财产案件”和“人格权侵权案件”基数。
- 日期计算：按起始日和间隔天数计算到期日，支持周末顺延。
- 利息/违约金计算：支持日利率、月利率、年利率及 360/365 天基准。
- 结果复制：单击计算结果即可复制，金额仅复制纯数字，方便填写文书。

## 安装

### 银河麒麟 ARM64

下载 `feecalculator_1.3.0_arm64.deb` 后执行：

```bash
sudo apt install ./feecalculator_1.3.0_arm64.deb
```

程序安装到 `/opt/feecalculator`，默认基数配置保存在 `/opt/feecalculator/config.json`。

### 从源码运行

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```
